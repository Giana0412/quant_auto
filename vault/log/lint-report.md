## 규칙

| | 규칙 | 왜 |
|---|---|---|
| L1 | 깨진 위키링크가 없을 것 | 링크가 끊기면 맥락 추적이 끊긴다 |
| L2 | 번호 표기(`#9는`)가 태그로 오인식되지 않을 것 | 태그 창이 쓰레기 태그로 찬다 |
| L3 | 모든 문서에 `created` 가 있을 것 | 언제 것인지 모르면 최신 여부를 못 판단한다 |
| L4 | 아무도 링크하지 않는 문서가 없을 것 | 검색으로만 닿는 문서는 사실상 묻힌다 |
| L5 | 고쳐진 문서에는 `updated` 가 있을 것 | git 이력과 대조해 판정한다 |
| L7 | `review_by` 가 지난 문서 보고 | 오래된 문서 정리 장치 |
