# 지호님 미팅 — 결정사항

## 결정사항

1. **Slack 검토 UX는 승인/반려만 노출한다.** 필드 수정 폼(respond) 없이, 출처 URL을 눌러 실존 대회인지 확인한 뒤 그 자리에서 바로 승인하는 형태. 운영사·대행사·스폰서는 별도 자동화로 채워지므로 Slack에서 수정할 필요 없음.
2. **파이프라인 구조는 확정.** 이후 작업은 Google Sheet 대신 CSV/JSON 등 가벼운 파일 + Git 자동 업데이트로 전환 (이 미팅 이전에 이상욱이 내린 방향을 재확인).
3. **DB 활용 1차 범위는 두 가지로 한정.** (1) 대회 날짜 기준 영업 시점 알림, (2) 스폰서 기반 유사 브랜드 카테고리별 리스트업. 메일 라벨링·딜 단계 트래킹은 현 단계에서 제외.
4. **목표 시점은 7월 말** (박지호 희망). 목표 날짜를 찍고 프로젝트화해서 실제 동작을 검증하기로 함.

## 미결정 / 보류

- OAO 맥락 연결 — 준범과 상무 간 의견 차로 두 사람이 별도 세션 후 결정. 어느 에이전트(심바/라피키/제3의 에이전트)에 붙일지 미정. 이 연결 없이도 현재 파이프라인은 동작함
- 영업 단계별 기한 수치(대회 3개월 전 시작, 2개월 전 협상 등) — 박지호가 이상욱과 논의해 확정 예정
- 세일즈맵(Salesmap) 연동 — 박지호가 실사용 중이 아니어서 보류. 우선 Slack 알림으로 진행
- 프로덕션(스튜디오) 이관 시점 — 맥미니 연동 완료에 종속. 그전까지는 dev에만 적재
- 빈 필드 재체크 루프의 수동 트리거 필요 여부 — 김규형이 일단 보류
