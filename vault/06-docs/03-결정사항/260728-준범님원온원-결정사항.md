# 준범님 원온원 — 결정사항

## 결정사항

1. **이벤트 리서치 에이전트 확장 순서는 "인리치먼트 → 국가 → 카테고리"로 확정.** 국가 확장을 먼저 해야 번역 UX까지 설계할 수 있고, 그 상태에서 카테고리를 늘려야 새 종목에도 번역/노출 관점이 함께 반영되기 때문.
2. **이번 주 우선순위는 enrich 품질 고도화.** 새 기능을 늘리는 것이 아니라, discover가 가져온 source URL 한 곳에서 최대한 많은 정보를 정확히 추출하는 데 집중.
3. **"소스 스카우트 스킬" 정규화는 후순위.** 별도 스킬을 만들기보다 Claude/터미널 세션으로 몇 번 수동 조사해서 유효한 해외 소스 목록을 먼저 확보하는 쪽이 효율적이라고 판단.
4. **옵시디언 검토의 목적은 "기록 축적"이 아니라 "파편화된 전사 정보의 단일 맥락 저장소화".** 깃·슬랙·구글 드라이브·노션으로 이원화된 상태에서는 AI가 전체 히스토리를 읽고 판단하기 어렵다는 문제의식이 출발점.
5. **깃과 옵시디언의 역할 분리 관점 설정.** 코드와 불변성 높은 문서는 깃에, 전사 공통 문서·맥락·운영 로그는 옵시디언으로 옮길 수 있는지 검토하는 방향.
6. **3주 일정 합의.** 이번 주(7/29~7/31) 인리치먼트 고도화 + 옵시디언 조사 / 다음 주(8/3~8/7) 국가 확장 + 번역 고려 + 옵시디언 테스트 / 그다음 주(8/10~8/14) 카테고리 확장 + 옵시디언 전사 도입 시도.

## 미결정 / 보류

- 옵시디언 전사 도입 여부 — 규형님 조사 결과(대체 범위, 연동 가능성, 프라이싱)를 보고 판단
- 카테고리 확장 범위 — 아워심볼 방향성에 맞는 이벤트인지, 스포츠 경기 전체를 다 포함할지 사전 협의 필요. 매일 반복되는 일반 야구 경기 같은 건 방향성과 다를 수 있다는 문제의식 제기됨
- 종목별 대표 소스 사이트 — 카테고리 확장 시 종목마다 별도 파악 필요, 현재 미확정
- 해외 이벤트 소스 목록 — 수동 조사로 확보하기로 했을 뿐 대상 사이트는 아직 미정

## 액션 아이템

**김규형 — 이번 주 (7/29~7/31)**
- enrich(인리치먼트) 고도화 — 한 사이트에서 최대한 많은 정보를 정확히 추출하도록 품질 개선
- 옵시디언 도입 필요성/이유 조사. 조사 포인트 5가지:
  - 현재 OAO 데이터가 어디에 어떻게 흩어져 있는지
  - 그중 무엇이 중복/누락/이원화되어 있는지
  - 옵시디언이 현재 프로세스를 어디까지 대체할 수 있는지
  - CLI / MCP / AI 연동 가능성
  - 스토리지 / 프라이싱 구조
- 모노레포 및 회사 정보 구조 파악

**김규형 — 다음 주 (8/3~8/7)**
- 국가 확장 진행 — discover 단계에 해외 이벤트 소스 추가, enrich 단계에 번역 고려 (예: 보스턴 마라톤처럼 한국 유저 관심 대상은 한국어 번역 UX 필요)
- Claude/터미널 세션 수동 조사로 유효한 해외 소스 목록 확보
- 옵시디언 개인 테스트 / 실무 테스트 병행

**김규형 — 그다음 주 (8/10~8/14)**
- 카테고리 확장 진행 — 마라톤 외 다른 스포츠 종목 조사/적용
- 옵시디언 전사 도입 시도

**김규형 — 상시**
- AI에게 시킨 작업은 반드시 본인이 결과를 검증 (소스 추천, 스킬 수정, 종목/사이트 추천 모두 해당)
- 막히는 지점은 혼자 오래 끌지 말고 준범님과 빠르게 싱크해서 방향 자체를 조정

**이준범**
- 카테고리 확장 범위(아워심볼에 맞는 이벤트 종목) 협의

## 참고

- 전사 불확실 항목: ClovaNote 자동 전사 기반으로 화자명·고유명사·수치 일부는 원문 재확인 필요
- 회의 성격: 이벤트 리서치 에이전트 3주 실행 계획 + 옵시디언 기반 조직 지식 구조 재설계 검토
