## KAN-23 — 횡단면 수익 예측 ML (Gu–Kelly–Xiu 2020 소규모 재현)

코드 `xsection.py` · 보고서 `runs/xsection.txt` (gitignore) · 장부 `kan-23-xsection` (18줄) + `kan-23-xsection-slices` (32줄).
실행: `cd ml && ../headline-sentiment/.venv/bin/python -m research.xsection` (예측 캐시 없으면 ~15분, M2 CPU).

**결론: 음성.** S&P 500 대형주 · 가격/거래량/실적 피처 21개 · 2017-01~2026-09 (117개월) 표본 밖에서
어떤 모델도 R²(0) 가 양수가 아니고, 월 순위 IC 는 +0.01~+0.02 (NW t ≤ 1.5), 10bp 비용 뒤 롱숏 샤프 ≤ 0.34.
LightGBM·신경망은 Ridge 를 넘지 못했다 (IC 차 |t| ≤ 1.0, Holm 보정 p 전부 ≈ 1). 최고 롱숏(GBM-d6)의 DSR 0.57.
GKX 의 "비선형 이득"은 이 표본에서 재현되지 않는다 — 신호 자체가 거의 없어서 나눌 이득이 없다.

### 설계 (실행 전에 고정)

- 패널 `monthly_panel` → `prepare` (날짜별 순위 + 중앙값 대체 + `_na`, 열 40개). 라벨 `y_ex` (베타조정 초과수익).
- `walk_forward(first_test=2017-01, refit=12, val=12)` — 매년 재학습. 2017 시작은 첫 폴드 안쪽 학습 24개월(하한) +
  검증 12개월로 가능한 가장 이른 시작. 검증으로 α·그루 수·에폭·L1 을 고르고 학습+검증으로 다시 학습.
- 모델: OLS-3(CLASSIC) · OLS-all · Ridge · Lasso · ENet(0.5) · LightGBM depth 1/2/3/6 (lr 0.02, min_child 500, L2 10,
  조기 종료 100) · NN1–3 (32 / 32-16 / 32-16-8, BatchNorm, L1 ∈ {1e-5, 1e-3} 폴드 안 선택, 시드 5개 앙상블).
- 추가 설정: 횡단면 라벨 `y_xs = y_ex − 날짜 평균`으로 학습(-xs) · SUE 피처 제외(-noSUE), 각각 Ridge/GBM-d3/NN3.

### 질문별 답

1. **기준.** OLS-3 (모멘텀·크기·단기반전)은 이 표본에서 신호가 없다(IC t 0.5, 롱숏 음수). 벌점 선형(Ridge/Lasso)은
   IC +0.02 (t 1.1–1.3) 로 가장 낫지만 통계적으로 0 과 구분되지 않는다. Ridge 는 10개 폴드 중 7개에서 α ≥ 1e4
   (사실상 0 으로 수축), Lasso 는 4개 폴드에서 계수 1–2개만 남겼다 — 검증이 "예측할 게 없다"고 말한 것.
2. **비선형.** LightGBM 은 조기 종료가 10개 폴드 중 4개에서 **1그루**에서 멈췄다. 신경망은 최적 에폭 중앙값 1–12.
   GBM·NN 모두 Ridge 대비 IC·롱숏·MSE 어느 쪽으로도 유의한 차이 없음. 횡단면 라벨(-xs)도 바꾸지 못했다.
3. **평가.** 위 표. 원수익(y_raw) 롱숏은 SPY β −0.4 ~ −0.9 — 모델들이 공통으로 "저베타·저변동성 롱"을 고른다.
   y_ex 기준으로 β 를 빼면 남는 α 는 연 +1~+7% (t ≤ 1.35).
4. **이득의 출처.** 순열 중요도(OOS IC 감소) 상위는 세 모델 모두 `beta` · `rvol_1m` · `rvol_3m` — 저위험 효과 하나다.
   GBM-d3 의 gain 은 52% 가 `ea_month`·`ea_next_exp` 인데 순열로는 IC 를 **떨어뜨리지 않거나 오히려 올린다** —
   MSE 목적함수가 발표 달의 큰 분산(평균이 아니라)을 맞히는 데 분할을 쓴다. 상호작용: 가법 GBM-d1 대비 d2/d3/d6 의
   IC 차는 전부 음수(t −0.6 ~ −0.8) → 상호작용 이득 없음. GBM-d1 − Ridge 도 IC +0.004 (t 0.5) → 가법 비선형 이득도 없음.
   부분의존: Ridge·NN3 는 beta·rvol 에 거의 직선(상위→하위 월 30bp 안팎), GBM-d3 는 같은 방향의 계단(폭 10–15bp).
5. **강건성.** 2017 은 Ridge 가 IC +0.098 (t 2.4) 로 좋았지만 2018–2020 IC −0.002, 2021–2026 +0.020 (t 1.1) — 전체
   결과의 상당 부분이 첫 해 하나다. 거래대금 작은 절반이 큰 절반보다 IC 가 약간 높다(Ridge 0.025 vs 0.015, NN3 0.027
   t 1.8 vs 0.010) — GKX 의 "소형주에 몰린다"와 같은 방향이지만 유의하지 않다. SUE 피처를 빼도 차이 |t| ≤ 1.5.
   실현 발표 달을 빼면 IC 가 오른다(Ridge 0.033 t 1.9, NN3 0.029 t 2.4), 발표 달만 보면 0 근처 — 이 피처들은
   발표 달 수익을 전혀 못 맞히고 그 달이 잡음만 더한다. 거래 가능한 대용(`ea_next_exp = 0`)도 같은 모양(NN3 IC t 2.4)이지만
   비용 뒤 롱숏은 +1% 안팎이고, 조각 32개 중 하나라 다중검정을 넘지 못한다.
6. **다중검정.** 설정 18개(장부 18줄) + 조각 32줄. 최고 롱숏 GBM-d6: 월 SR 0.098, SR0 0.084 → DSR 0.57
   (깎지 않은 PSR 0.87). 모델 vs Ridge 16개 비교의 Holm p: IC 차 · LS10 차 전부 1.00, DM 최소 0.97.

### 주의

- 점검 실행(XS_DEV, 2017–2018 두 폴드, 별도 장부)을 본 뒤 `-xs` 설정을 추가했다. 본 실행 전 결과를 본 것은 그 두 폴드뿐이고
  `-xs` 는 장부 N 에 들어 있다.

  상승장(2017–2026)에서는 고베타 종목의 y_ex 가 기계적으로 낮게 나온다 — 모델이 찾은 "저베타" 신호의 일부는 라벨
  구성의 산물일 수 있다(원수익 롱숏 β −0.9). 다음 단계: Vasicek 수축 β 로 라벨을 만들어 다시 본다.
- 재무 피처(가치·수익성·투자)가 없다 — GKX 이득의 큰 부분이 그쪽이다. 대형주 ~450종목 · 117개월은 월 IC 차 0.01 을
  가릴 검정력이 없다(IC 표준오차 ≈ 0.015).
- 생존 편향 · 상폐 수익 0 · 차입비 없음 (README 한계).
- 맥에서 LightGBM·torch 가 각자 libomp 를 실어 한 프로세스에서 섞으면 멈추거나 세그폴트 → 둘 다 1 스레드로 고정.

## KAN-24 — 종목 실현변동성 예측: ML vs HAR (2026-11-26)

코드 `research/vol.py` · 출력 `runs/vol.txt` (gitignore) · 장부 `kan-24-vol` (N = 33 시도 = 11 모델 × 3 h).

**설정.** 일간 패널 1.43M 행(S&P 500 편입 이력, 585 티커). 라벨 = t+1…t+h 일간 r² 평균(분산), h = 1·5·22.
확장창 walk-forward: 시험 2017-01 ~ 2026-11(10 블록, 매년 재학습), 학습 라벨이 시험 시작 전에 끝나도록 퍼지,
마지막 12개월은 검증(조기 종료 + 분산 배율 c 만). 공통 표본 ~1.13M 행 · ~2,480일. 손실은 MSE(log RV)와 QLIKE(분산),

다른 기준: HAR-mkt 는 HAR 과 사실상 같다(h=5 QLIKE +2.6%, Holm 0.95). EWMA(RiskMetrics) ≈ HAR(h=22 MSE-log −8.8%).
종목별 HAR 은 풀링보다 나쁘다(h=22 QLIKE −22%) — 순위 IC 는 오르지만(0.60 vs 0.57) 수준 추정이 시끄럽다.
순위 IC(날짜별 평균): HAR 0.23 / 0.44 / 0.57 → LGBM-full 0.27 / 0.55 / 0.69 (h = 1/5/22).

**어디서 이기나**
- **비선형이 아니라 정보다.** HAR 피처만 넣은 LightGBM 은 HAR 과 같다(모든 h 에서 |DM| < 1.6). 같은 피처의 선형
  OLS(HARX-lin)와 LightGBM 의 차이도 유의하지 않다(DM +0.2 ~ +1.8, Holm 1). LSTM(최근 60일 수익)은 HAR 을 못 넘고
  QLIKE 에서는 HARX-lin 보다 유의하게 나쁘다(h=1·5 Holm < 1e−3).
- **실적 발표 달력이 가장 큰 몫.** 사전 투영한 다음 발표일(1년 전 같은 분기 d0 + 364일; 실제와 |오차| 중앙값 1일, ±7일 94%)을
  빼면(LGBM-noearn) h=5 QLIKE 이득이 15.9% → 7.0%. 라벨 창에 발표가 있는 행(h=1: 1.6%, h=5: 8%)에서 LGBM-full 의
  QLIKE 가 43~49% 낮고, h=1·5 QLIKE 총 이득의 61~72% 가 이 행들에서 나온다. h=22 는 발표 창 이득(−14.5%)을 나머지 행의
  손실이 거의 상쇄한다 → QLIKE 무의미, MSE-log 만 유의.
- **레버리지·하방 준분산도 실제로 기여**(문헌과 일치하는 부분): 빼면(LGBM-nolev) h=1 QLIKE 이득 5.2% → 3.0%, h=22 MSE-log 14.9% → 11.8%.
  다만 선형 항으로 충분하다 — 비선형 상호작용이 필요하다는 증거는 없다.
  → Christensen–Siggaard–Veliyev(2023)의 "이득은 주로 비선형에서" 는 **재현되지 않음**(일간 r² 대용치·피처 구성이 다르다).
- **고변동 국면(SPY 22일 RV 상위 10%)에서는 ML 이 HAR 보다 나쁘다**(LGBM-full QLIKE +6% / +6% / +20%, 유의하지 않음; LSTM +20~109%).
  이득은 평온한 날과 발표 직전에 몰린다. 거래대금 상·하위 1/3 간 차이는 작다(하위가 약간 더 개선).
- 민감도(LGBM-sched, 🔴 "발표일은 2주 전 확정" 가정으로 실제 다음 d0 를 14일 안에서만 사용, Holm 밖): h=1 QLIKE 이득
  5.2% → 8.1%. 투영만으로 확정 일정 정보의 대부분을 얻는다.

**VaR (1일 99%, 종목별, 2017~2026)** 정규 분위로는 모든 모델이 1.5~1.6% 위반(과소). 필터드 HS(직전 12개월 표준화 수익의 1% 분위):
EWMA 1.09%(종목별 Kupiec 기각 4%), HARX-lin 1.10%(13%), HAR-mkt 1.14%(27%), LGBM-full 1.21%(27%), HAR 1.31%(31%), LSTM 1.54%(58%).
→ 예측 손실 개선이 VaR 커버리지 개선으로 그대로 이어지지 않는다. 발표 없는 날의 σ̂ 를 낮추는 모델(LGBM-full)이 꼬리에서는 손해.

**결론.** HAR 위 이득은 크고 유의하지만(h=5 QLIKE −16~18%, Holm < 1e−15), 출처는 ML 이 아니라 **피처 정보**(사전 투영 실적
일정 + 레버리지/하방 준분산 + 장기 RV·크기) 이고 선형 HAR-X 로 다 얻는다. 실전 권장: HAR-X(OLS) + 실적 달력, 위기 국면 대비는 EWMA/HAR-mkt 와 결합.

**한계.** RV 는 일간 r² 대용치(장중 자료 없음) — h=1 log 라벨은 log χ² 잡음이 커서 MSE-log 는 참고용(Patton 2011, QLIKE 가 1차).
