## A-1. 🔴 obsidian-git 을 **pull 전용**으로

**출처**: [Vinzent03/obsidian-git](https://github.com/Vinzent03/obsidian-git) ★11.7k — 우리가 지금 쓰는 플러그인

### 어떻게 동작하나
`autoPullInterval` · `autoSaveInterval`(커밋) · `autoPushInterval` 이 **각각 따로** 설정된다.

**우리 현재 설정(실측)** — `vault/.obsidian/plugins/obsidian-git/data.json`:
```
autoSaveInterval: 10   autoPullInterval: 10   autoPushInterval: 10   autoPullOnBoot: true
```
**셋 다 켜져 있다.** 즉 사람이 Obsidian 에서 문서를 직접 고치면 10분 뒤 자동으로 커밋·푸시된다.

### 우리에게 적용하면
`autoSaveInterval`·`autoPushInterval` 을 **끄고** `autoPull` 만 남긴다.

| 장점 | 단점 |
|---|---|
| ✅ **설정 3개 변경. 코드 0줄** | ⚠️ 각자 기기에서 한 번씩 바꿔야 함 (온보딩 항목으로) |
| ✅ 읽는 사람이 **stale 을 안 본다** — 앱이 알아서 당겨옴 | ⚠️ 앱이 꺼져 있으면 여전히 안 당김 (읽지도 않으니 무해) |
| 🔴 **제1 운영원칙이 구조로 강제된다** — 직접 고쳐도 커밋이 안 되고 다음 pull 에 덮어써짐 | 🔴 **모르고 고친 사람은 작업을 잃는다.** 온보딩에서 반드시 알려야 함 |
| ✅ 규칙이 아니라 구조라 지켜짐 ([GitLab 슬랙 90일](https://handbook.gitlab.com/handbook/company/culture/all-remote/handbook-first/)과 같은 원리) | |

**판정**: **채택 권장.** 비용 대비 효과가 가장 크다. 단 "덮어써짐"을 반드시 공지.

## A-2. 🔴 `.gitattributes` 에 `merge=union`

**출처**: git 표준 기능. **위키에 적용한 외부 사례는 못 찾았다** — 아래 숫자는 내가 직접 잰 것이다.

### 왜 필요한가 — 실측

준범님 규약대로 ingest 트랜잭션은 **문서 + `index.md` + 당일 로그** 셋을 항상 건드린다.
빈 레포 두 대(A·B)를 만들어 **같은 날 각자 ingest** 를 시켰다.

```
결과:  🔴 CONFLICT — wiki/index.md
       🔴 CONFLICT — log/2026-08/2026-08-14.md
```

**한 명도 같은 문서를 안 건드렸는데 충돌한다.** 둘 다 파일 **끝에 줄을 추가**했기 때문이다.
git 은 "양쪽이 마지막 줄 뒤에 추가"를 자동 병합하지 못한다.

> CLAUDE.md 에 *"append 성격 파일 log·index 는 **양쪽 보존이 정답**"* 이라고 적혀 있는데,
> 그건 **정답이 무엇인지**를 말한 것이지 git 이 자동으로 해준다는 뜻이 아니다.
> 현재 설계대로면 **같은 날 두 명이 일할 때마다 에이전트가 충돌을 푼다.**

### 고치면

```gitattributes
wiki/index.md   merge=union
log/**/*.md     merge=union
```

같은 실험을 다시:
```
✅ 자동 병합 — 양쪽 다 보존.  중복 줄 0개
- [[일본 진출]]
- [[확장 로드맵]]     ← A
- [[글로벌 전략]]     ← B
```

| 장점 | 단점 |
|---|---|
| ✅ **두 줄로 가장 흔한 충돌이 사라진다** | 🔴 **append 파일에만 안전하다.** 본문 페이지에 걸면 안 됨 |
| ✅ 에이전트가 충돌 처리에 쓰는 왕복이 없어짐 | ⚠️ 양쪽이 **같은 줄을 고치면** 두 버전이 다 남아 이상해질 수 있음 |
| ✅ 로그·index 는 원래 "양쪽 보존이 정답"이라 의미가 맞음 | ⚠️ 순서가 커밋 순이 아니라 병합 순 — index 정렬이 흐트러질 수 있음 |
| ✅ 다중 커밋터 붙기 **전에** 해두면 무비용 | 🔴 위키에 적용한 **외부 선례를 못 찾음** (git 표준 기능이긴 함) |

**판정**: **채택 권장.** 단 대상 파일을 `index.md` 와 `log/**` 로만 한정.

| 장점 | 단점 |
