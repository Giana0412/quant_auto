# 노션(Notion) 활용 강의 — 결정사항

## 결정사항
- 없음 (강의 후속 액션 제안) — 외부 강사의 노션 활용 강의로, 공식 결정 사항은 없음. 아래 액션 아이템은 강의 내용을 바탕으로 제안된 후속 검토 항목임

## 액션 아이템
- [미정] 현재 구글 시트로 관리 중인 영업 DB를 노션의 **프로젝트 DB + 태스크 DB(관계형)** 구조로 전환 검토
- [미정] 고객별 개별 페이지 + 영업 단계 보드 뷰 설계
- [미정] 계약 완료 시 후속 업무/서류 자동 생성 자동화 설정
- [미정] 회의록 AI 노트 기능 테스트 → 영업 상태 반영 자동화 프로토타입 제작
- [미정] 계정 구조(대표 계정 vs 공용 계정 vs 게스트) 정리로 비용 최적화
- [미정] 페이지별 접근 권한(특히 민감 정보) 점검

## 보류사항
- 위 6개 항목 모두 담당자·기한 미지정 상태 — 실제 적용 여부와 우선순위는 별도 논의 필요
- 노션 기능 제약으로 당장 해결이 불가한 항목: 대시보드 전년 대비 비교 그래프 미지원, AI 노트 화자 인식(개인 매핑) 불완전

## 참고
- 전사 불확실 항목: ClovaNote 자동 전사 특성상 고유명사·수치 오기 가능 (예: "노선"/"노션", "에어 기능"/"AI 기능")
- 전사본은 2부 개인질문 세션(9분 34초)만 보존, 1부 강의(약 42분) 원문은 없음
