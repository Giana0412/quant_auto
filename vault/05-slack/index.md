# 05-slack — Slack 원본 (raw)

**여기 있는 파일은 사람이 고치지 않는다.** 원본 보존 영역이다.

## 어떻게 들어오나

```
Slack #test_ob ──▶ slack-collect.sh (1시간마다) ──▶ 이 폴더
```

`.automation/slack_collect.py`가 수집한다. **Obsidian 앱과 무관하게** launchd가
직접 돌린다 — 예전에는 `slack-sync` 플러그인이 했는데, 앱이 켜져 있어야만 동작해서
2026-08-06부터 6일간 조용히 멈춰 있었다.

## 어디로 나가나

```
이 폴더 ──ingest──▶ 06-docs/{01-전사본, 02-정리본, 03-결정사항}
```

`process-slack-docs.sh` 2단계가 [[../06-docs/_템플릿-가이드|템플릿 가이드]] 형식에 맞춰
3종 문서를 만든다. 원본은 여기 그대로 남는다.

## 파일명 규칙

```
{YYYYMMDD}_{HHMM}_{작성자}.md          예: 20260810_0952_김규형.md
{YYYYMMDD}_{HHMM}_{작성자}-2.md        같은 사람이 같은 분에 두 번 말한 경우
```

본문에서 제목을 뽑지 않는다. 그래서 **같은 메시지는 언제 다시 수집해도 같은 파일명**이
되고, 재실행해도 중복이 생기지 않는다.

> 2026-08-06 이전 파일 5개는 플러그인이 만든 것이라 이름 규칙이 제각각이다
> (`20260806_10.md`, `20260806_U0BC06201S5.md` 등). 뒤 단계가 파일명이 아니라
> 내용으로 날짜를 추론하므로 섞여 있어도 문제되지 않아 그대로 둔다.

## 수집되지 않는 것

| | 이유 |
|---|---|
| 봇이 올린 메시지 | 자동화가 게시한 글이 다시 원본으로 들어오는 되먹임을 막는다 |
| `채널에 참여함` 등 시스템 메시지 | 내용이 없다 |
| 이미지·PDF·덱 등 바이너리 | vault에는 md만 들어간다. Slack 링크만 남긴다 |
