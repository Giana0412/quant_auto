## KAN-24 — 종목 실현변동성 예측: ML vs HAR (2026-11-26)

코드 `research/vol.py` · 출력 `runs/vol.txt` (gitignore) · 장부 `kan-24-vol` (N = 33 시도 = 11 모델 × 3 h).

**설정.** 일간 패널 1.43M 행(S&P 500 편입 이력, 585 티커). 라벨 = t+1…t+h 일간 r² 평균(분산), h = 1·5·22.
확장창 walk-forward: 시험 2017-01 ~ 2026-11(10 블록, 매년 재학습), 학습 라벨이 시험 시작 전에 끝나도록 퍼지,
마지막 12개월은 검증(조기 종료 + 분산 배율 c 만). 공통 표본 ~1.13M 행 · ~2,480일. 손실은 MSE(log RV)와 QLIKE(분산),
날짜별 횡단면 평균 손실로 DM(HLN, lag = max(h−1, NW)). Holm 가족 = 66개 DM(9개 모델 vs HAR + 비선형 대조 2개, × 3 h × 2 손실).

다른 기준: HAR-mkt 는 HAR 과 사실상 같다(h=5 QLIKE +2.6%, Holm 0.95). EWMA(RiskMetrics) ≈ HAR(h=22 MSE-log −8.8%).
종목별 HAR 은 풀링보다 나쁘다(h=22 QLIKE −22%) — 순위 IC 는 오르지만(0.60 vs 0.57) 수준 추정이 시끄럽다.
순위 IC(날짜별 평균): HAR 0.23 / 0.44 / 0.57 → LGBM-full 0.27 / 0.55 / 0.69 (h = 1/5/22).

**어디서 이기나**
- **비선형이 아니라 정보다.** HAR 피처만 넣은 LightGBM 은 HAR 과 같다(모든 h 에서 |DM| < 1.6). 같은 피처의 선형
  OLS(HARX-lin)와 LightGBM 의 차이도 유의하지 않다(DM +0.2 ~ +1.8, Holm 1). LSTM(최근 60일 수익)은 HAR 을 못 넘고
  QLIKE 에서는 HARX-lin 보다 유의하게 나쁘다(h=1·5 Holm < 1e−3).
- **실적 발표 달력이 가장 큰 몫.** 사전 투영한 다음 발표일(1년 전 같은 분기 d0 + 364일; 실제와 |오차| 중앙값 1일, ±7일 94%)을
  빼면(LGBM-noearn) h=5 QLIKE 이득이 15.9% → 7.0%. 라벨 창에 발표가 있는 행(h=1: 1.6%, h=5: 8%)에서 LGBM-full 의
  QLIKE 가 43~49% 낮고, h=1·5 QLIKE 총 이득의 61~72% 가 이 행들에서 나온다. h=22 는 발표 창 이득(−14.5%)을 나머지 행의
  손실이 거의 상쇄한다 → QLIKE 무의미, MSE-log 만 유의.
- **레버리지·하방 준분산도 실제로 기여**(문헌과 일치하는 부분): 빼면(LGBM-nolev) h=1 QLIKE 이득 5.2% → 3.0%, h=22 MSE-log 14.9% → 11.8%.
  다만 선형 항으로 충분하다 — 비선형 상호작용이 필요하다는 증거는 없다.
  → Christensen–Siggaard–Veliyev(2023)의 "이득은 주로 비선형에서" 는 **재현되지 않음**(일간 r² 대용치·피처 구성이 다르다).
- **고변동 국면(SPY 22일 RV 상위 10%)에서는 ML 이 HAR 보다 나쁘다**(LGBM-full QLIKE +6% / +6% / +20%, 유의하지 않음; LSTM +20~109%).
  이득은 평온한 날과 발표 직전에 몰린다. 거래대금 상·하위 1/3 간 차이는 작다(하위가 약간 더 개선).
- 민감도(LGBM-sched, 🔴 "발표일은 2주 전 확정" 가정으로 실제 다음 d0 를 14일 안에서만 사용, Holm 밖): h=1 QLIKE 이득
  5.2% → 8.1%. 투영만으로 확정 일정 정보의 대부분을 얻는다.

**VaR (1일 99%, 종목별, 2017~2026)** 정규 분위로는 모든 모델이 1.5~1.6% 위반(과소). 필터드 HS(직전 12개월 표준화 수익의 1% 분위):
EWMA 1.09%(종목별 Kupiec 기각 4%), HARX-lin 1.10%(13%), HAR-mkt 1.14%(27%), LGBM-full 1.21%(27%), HAR 1.31%(31%), LSTM 1.54%(58%).
→ 예측 손실 개선이 VaR 커버리지 개선으로 그대로 이어지지 않는다. 발표 없는 날의 σ̂ 를 낮추는 모델(LGBM-full)이 꼬리에서는 손해.

**결론.** HAR 위 이득은 크고 유의하지만(h=5 QLIKE −16~18%, Holm < 1e−15), 출처는 ML 이 아니라 **피처 정보**(사전 투영 실적
일정 + 레버리지/하방 준분산 + 장기 RV·크기) 이고 선형 HAR-X 로 다 얻는다. 실전 권장: HAR-X(OLS) + 실적 달력, 위기 국면 대비는 EWMA/HAR-mkt 와 결합.

**한계.** RV 는 일간 r² 대용치(장중 자료 없음) — h=1 log 라벨은 log χ² 잡음이 커서 MSE-log 는 참고용(Patton 2011, QLIKE 가 1차).
LightGBM 은 폴드당 30만 행 표본·고정 하이퍼파라미터, LSTM 은 15만 행 · 1층 32 유닛 — 더 큰 모델은 시험 안 함.
모든 모델은 검증 12개월을 적합에 쓰지 않고(배율만) 블록 안에서 고정. 생존 편향(편출 종목 중 가격 남은 것만), 발표일 이력은 Yahoo 현재 저장값.
풀링 Kupiec 는 같은 날 위반 군집 때문에 과대 유의. 시도 N = 33 은 서로 상관된 설정이라 독립 시도 수의 상한.
